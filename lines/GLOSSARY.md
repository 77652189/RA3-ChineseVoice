# 红警3 中文配音 · 翻译规范与术语表

## 翻译原则
1. **这是配音稿，不是字幕**：短、口语、有力，读出来顺口。宁可意译，不要翻译腔。
2. **时长贴近原版**：普通话约每秒 4~5 个字。`seconds` 列是原版时长，中文字数尽量不超过 `seconds × 5`，短句（<1 秒）控制在 2~4 个字。
3. **保留人设**：
   - 苏联：粗犷、豪迈、带俄式幽默，可用“同志”“为了祖国”“为了母亲俄罗斯”等，但别每句都加。
   - 帝国：恭敬、武士道、略带中二，“天皇陛下”“荣誉”“为了帝国”；偶尔的日语词（Hai! 等）译成中文意思（“是！”“遵命！”）。
   - 盟军：职业、自信、略带美式俏皮。
   - 机器 / AI 单位（超级要塞、未来坦克等）：冷静、略呆萌。
   - 谭雅、娜塔莎、百合子等英雄：保留性格（谭雅嚣张、娜塔莎冷酷、百合子冷淡神秘）。
4. **经典台词**沿用国内玩家熟知的译法（如 Kirov reporting → “基洛夫报到”）。
5. **标点**：句末用中文标点（。！？），句中用逗号。不要用括号、英文、阿拉伯数字（数字写成汉字，如“一万”）。
6. **没有实际台词的**（`en` 为 `(none)`、只有喘气/笑声/吼叫/哼声、或明显是听写乱码且听不出内容的）：`zh` 留空字符串，并在 note 里写原因。这类保留原声。
7. 听写可能有错（RA3 口音重），按游戏语境推断正确意思再翻；拿不准的在 note 里写“听写存疑”。

## 播报（EVA）
三个阵营各有一位战场播报员：盟军（冷静干练的女声）、苏联（严肃军官腔）、帝国（恭敬的女声）。播报用语要像正式战场通报：简洁、准确、语气平稳。
常用：Building → 建造中；Construction complete → 建造完成；Unit ready → 单位就绪；Unit lost → 单位损失；Our base is under attack → 我方基地遭到攻击；Low power → 电力不足；Insufficient funds → 资金不足；Reinforcements have arrived → 援军已抵达；Enemy superweapon detected → 侦测到敌方超级武器；Battle control terminated → 战场控制终止；You are victorious → 你胜利了；You have lost → 你失败了。

## 剧情对白（mission 批次）
任务对白、单位介绍旁白、训练关讲解。大部分行有官方字幕：`zh_official` 是官方繁体中文字幕转成的简体（OpenCC 台湾→大陆用语）。
1. **有 `zh_official` 的行：以它为底稿，尽量少改。** 简体文字组件里玩家看到的就是这份字幕，配音和字幕说法一致最好。只在下面几种情况改：
   - 台湾用语或书面腔，读出来别扭（“察看”→“查看”、“部队”留着、“你必尽一切所能”→“你必须竭尽全力”）；
   - 对苏联的称呼：官方常写“俄军/俄国人”，配音统一改成“苏军/苏联人”（引用原文骂人的“俄国佬”可保留）；
   - 单位名和上面术语表不同的，改成术语表的叫法（例：基洛夫飞船→基洛夫飞艇）；
   - 明显漏译、错译（对照 `en`），或者字幕比原声少了半句 / 多了半句：以原声 `en` 为准补全；
   - 太长：字数（不含标点）超过 `seconds × 5.5` 时压缩，保留关键信息；
   - 含阿拉伯数字、英文字母的，改成汉字（“X-1”这类型号可写成“艾克斯一号”）；
   - TTS 多音字容易读错的地方换个说法（教训：弹 tán/dàn、乐、行 háng/xíng、重 zhòng/chóng、长 cháng/zhǎng、还 hái/huán、为 wèi/wéi、得 de/děi、着 zhe/zháo、干 gàn/gān；能换词就换，比如“炮弹”可留，“弹药”可留，“子弹打光了”好过“弹尽”）。
   - 去掉字幕里的省略号堆叠和破折号，用逗号、句号表达停顿；只保留 。！？，、
2. **没有 `zh_official` 的行：按 `en` 翻译**，口语、贴合角色。`en` 是语音识别听写，可能有错，按语境推断；拿不准写 note“听写存疑”。只有喘气、惨叫、笑声、无意义喊叫的：`zh` 留空，note 写原因（保留原声）。
3. 人名、地名沿用 `zh_official` 里的官方译名（同一角色在各行保持一致）。
4. 训练关（MT 开头）是教程讲解，语气耐心清楚；单位介绍（MAIn_/MSIn_/MIIn_）是纪录片式旁白，平稳庄重。

## 过场视频（movie 批次）
剧情过场、任务简报、任务中的真人通话视频、遭遇战 AI 指挥官视频。每行是视频里的一句（或半句）字幕，按时间轴单独配音后放回原位置。规则同“剧情对白”第 1~4 条（以 `zh_official` 为底稿尽量少改，俄军→苏军，术语表，大陆用语，多音字，数字和字母写汉字），另外：
1. **时间是硬约束**：`slot` 是这一句从开始到下一句开始的秒数，中文字数（不含标点）不能超过 `slot × 4.5`，最好接近 `dur × 4.5`。超了就压缩。
2. **一行对应一段时间**：官方字幕常把一句话拆成几行（“我是库可夫将军，” / “今天将带给你们失败的人。”）。每行只写这一段时间里说的内容，不要把后一行的内容挪上来；中文语序不同时，允许在相邻两行之间小幅调整措辞，让每行单独读出来也通顺。
3. 人设：苏联将军库可夫粗暴傲慢；苏联总理狡猾圆滑；帝国太子和天皇庄重；谭雅嚣张；盟军总统强硬；娜塔莎冷酷；百合子冷淡神秘；情报官职业干练。人名一律沿用 `zh_official`（官方字幕）里的叫法，不要自己起名。
