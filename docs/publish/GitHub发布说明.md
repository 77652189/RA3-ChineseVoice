### 安装
解压后运行「{SETUP_EXE}」，勾选内容后点“安装 / 更新”。不改版本号，联机选 1.12 / 1.13 不受影响；随时可以全部卸载，原文件有备份。

安装器没有数字签名，Windows 可能提示“已保护你的电脑”，点“更多信息”→“仍要运行”。可以核对校验码：

```
SHA-256  {SETUP_SHA256}
```
