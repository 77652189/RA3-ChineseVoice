## 二、已完成要点（细节见代码）
- 剧情对白：流式语音 = 头在 `audio.bin` + RefPack 压缩的 SNS 块（`ra3voice/game.py`）；质检停顿门槛随句长放宽（`ra3voice/pauses.py`）。
- 过场视频：EA-XA v2 编解码（`ra3voice/eaxa.py`）；只替换人声声道；合成按英文字幕时间轴放回、超时最多加速 1.5 倍、按 10 ms 能量裁掉噪声（`ra3voice/movie.py`）。最终原版 274 句加速、8 句截尾，起义时刻 128 句加速、6 句截尾。
- 文字：字幕以配音稿为准、界面名称以术语表 / 配音多数说法为准（`ra3voice/textpack.py`）；打包时检查缺字（`ra3cv.missing_glyphs`）。
- 安装器：`红警3中文配音安装器.exe`（`installer/gui/Installer.cs`，系统自带 csc 编译，无签名），与 `installer/installer.ps1` 在 5 种组合下结果逐字节一致；ps1 和 bat 作为 files\ 里的备用。

## 三、路线与优先级
1. 等用户游戏内检查：过场、简报、通话视频的配音与字幕；帝国超级武器等界面名称。
2. 按反馈修改：改 `lines/<批次>_zh_*.json` → `tools/merge_zh.py` → 重配对应句 → `ra3cv.py build/release/install`。
3. 发布：三种安装包（`ra3cv.py release` → `release/红警3中文配音MOD_v1.0_{完整版,原版,起义时刻}.zip`，1.32 GB / 808 MB / 514 MB）；安装器检测到包里没有的游戏时提示该下哪个版本。分发计划：B 站演示视频做入口（`release/红警3中文配音_演示.mp4`、`release/B站投稿文案.txt`，由 `tools/make_demo.py` 生成），文件放 123 云盘 + 百度网盘镜像；GitHub 暂不放 MOD 文件。
